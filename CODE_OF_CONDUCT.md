# Code of conduct

Be respectful and specific when discussing code and ideas. Harassment, personal attacks, and sharing another person's private information are not acceptable in issues, pull requests, or other project spaces. Maintainers may edit, hide, or remove comments and may restrict participation to keep discussions useful and safe.

Use GitHub's **Report content** feature for abusive content. For a concern involving this project's discussions that is safe to discuss publicly, open an issue and link the relevant discussion. Do not post private personal details in an issue.
