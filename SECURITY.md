# Security policy

Security fixes are considered for the current release line. The current release line is `0.2.x`.

Do not disclose a suspected vulnerability in a public issue. Use **Security → Report a vulnerability** to send a private report to the maintainers. Include the affected version or commit, impact, and reproduction steps without sharing API keys or private response data. If private vulnerability reporting is unavailable, email info@pinkrooster.nl without including secrets.
