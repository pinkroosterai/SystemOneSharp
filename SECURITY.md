# Security policy

Security fixes are considered for the current release line. This project has no published package yet.

Do not disclose a suspected vulnerability in a public issue. Once this repository is public, use **Security → Report a vulnerability** to send a private report to the maintainers. Include the affected version or commit, impact, and reproduction steps without sharing API keys or private response data. If private vulnerability reporting is unavailable, open an issue asking for a private contact channel without including vulnerability details.
